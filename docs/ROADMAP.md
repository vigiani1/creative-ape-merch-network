# Roadmap

## Milestone 1: Foundation
Next.js/TypeScript/Tailwind, Supabase SSR structure, initial schema/RLS, admin shell, portal shell, public storefront/product routes, Stripe route foundation, documentation.

## Milestone 2: Organizations, stores, products
Authenticated admin, organization CRUD, membership management, store CRUD, logo upload, theme controls, product CRUD, variants, multiple images/video metadata, product templates.

## Milestone 3: Commerce
Cart, variant-aware checkout, order creation, Stripe test mode, verified webhook processing, immutable financial snapshots, ledger, revenue-share engine, refunds.

## Milestone 4: Operations
Production/fulfillment queue, batch workflow, organization dashboards, reports, payout tracking, export formats.

## Milestone 5: Deployment and QA
Connect Supabase, configure Vercel, environment variables, test data, end-to-end validation, security review, performance review.

## Later
Stripe Connect, eligible alternative wallets/payment methods, custom domains, automated payouts, coupons, inventory, advanced analytics, personalization, richer logo color extraction.
